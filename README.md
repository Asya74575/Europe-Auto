# Авто из Европы — лендинг «Вестлайн»

Концепт лендинга для портфолио: подбор и пригон автомобилей с пробегом из Европы в Минск под ключ.

Компания «Вестлайн», цены, отзывы, пригнанные машины и контакты — **условные**: всё придумано для показа дизайна. Форма заявки показательная и никуда не отправляет данные.

## Что внутри

- `index.html` — главная: первый экран, откуда машины, как работаем, пригнанные автомобили, пакеты услуг, калькулятор «под ключ», о компании, отзывы, вопросы, заявка;
- `legal/` — политика конфиденциальности, согласие на обработку данных, cookie (шаблонные тексты);
- `404.html` — страница «не найдено»;
- `assets/` — стили, скрипты, шрифты.

Чистые HTML, CSS и JavaScript без сборки. Открыть — двойным щелчком по `index.html`.

## Шрифты и фото

- Шрифты Alumni Sans и Geist — SIL Open Font License 1.1, тексты лицензий лежат рядом со шрифтами в `assets/fonts`.
- Фото — Pexels (лицензия Pexels), номера машин и надписи размыты. Машины на фото — иллюстрации, а не реальные машины клиентов.
